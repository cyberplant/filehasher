# FileHasher v2

A modern, high-performance file hashing utility with parallel processing, multiple algorithms, and beautiful progress bars.

## Features

- **Multiple Hash Algorithms**: MD5, SHA-1, SHA-256, SHA-512, Blake2B, Blake2S with benchmarking
- **Advanced Multiprocessing**: Parallel processing with individual thread progress bars
- **Smart Load Balancing**: Distribute files by total bytes, not count, across threads
- **File-Level Progress**: Real-time progress indication within large files
- **Incremental Updates**: Update only changed files with `--update` parameter
- **Progress Reporting**: Beautiful progress bars using Rich library
- **Duplicate Detection**: Find duplicates within hash files
- **Cross-Directory Comparison**: Compare hash files from different directories
- **Script Generation**: Generate bash scripts for cleanup and synchronization
- **Benchmarking**: Test hash algorithm performance on your machine
- **Metadata Headers**: Rich metadata in hash files for traceability
- **Symlink Support**: Handle symbolic links gracefully as commented entries
- **Signal Handling**: Graceful CTRL-C interruption with process cleanup

cd filehasher_v2

## Quick Start

### Generate Hash File

```bash
# Basic usage
python -m filehasher_v2 generate /path/to/directory

# With options
python -m filehasher_v2 generate /path/to/directory --algorithm SHA-256 --workers 4

# Update existing hash file (only changed files)
python -m filehasher_v2 generate /path/to/directory --update

# Follow symlinks
python -m filehasher_v2 generate /path/to/directory --follow-symlinks

# Quiet mode
python -m filehasher_v2 generate /path/to/directory --quiet
```

### Find Duplicates

```bash
# Find duplicates in a hash file
python -m filehasher_v2 duplicates file.hashes

# Custom output script
python -m filehasher_v2 duplicates file.hashes --output my_cleanup.sh
```

### Compare Hash Files

```bash
# Compare two hash files
python -m filehasher_v2 compare file1.hashes file2.hashes

# Custom output script
python -m filehasher_v2 compare file1.hashes file2.hashes --output my_sync.sh
```

### Benchmark Algorithms

```bash
# Benchmark all algorithms
python -m filehasher_v2 benchmark

# Benchmark specific algorithms
python -m filehasher_v2 benchmark --algorithms "md5,sha256,blake2b"

# Custom test file size
python -m filehasher_v2 benchmark --size 50
```

### Get Hash File Information

```bash
# Display hash file information
python -m filehasher_v2 info file.hashes
```

## Command Options

### Generate Command
- `--algorithm, -a`: Hash algorithm (md5, sha1, sha256, sha512, blake2b, blake2s)
- `--output, -o`: Output hash file path
- `--workers, -w`: Number of worker processes (default: CPU count)
- `--quiet, -q`: Suppress progress output
- `--follow-symlinks`: Follow symbolic links
- `--update, -u`: Update existing hash file, only hash changed files

### Duplicates Command
- `--output, -o`: Output script path (default: cleanup_duplicates.sh)

### Compare Command
- `--output, -o`: Output script path (default: sync_directories.sh)

### Benchmark Command
- `--size, -s`: Test file size in MB (default: 10)
- `--algorithms, -a`: Comma-separated list of algorithms to test
- `--iterations, -i`: Number of iterations per algorithm (default: 3)

## Hash File Format

Hash files include metadata headers and use pipe-delimited format with algorithm prefixes:

```
# Generated by filehasher 2.0.0
# Machine: hostname.local
# Base directory: /path/to/directory
# User: username
# Generated: 2024-01-15 14:30:25
SHA256:hash_value|secondary_hash|directory|filename|size|inode|mtime
MD5:hash_value|secondary_hash|directory|filename|size|inode|mtime
hash_value|secondary_hash|directory|filename|size|inode|mtime
```

**Algorithm Format:**
- Non-MD5 algorithms: `ALGORITHM:hash_value` (e.g., `SHA256:abc123...`)
- MD5 (default): `hash_value` (no prefix for backwards compatibility)
- Symlinks: `# SYMLINK|directory|filename|size|inode|mtime`

## Generated Scripts

### Duplicate Cleanup Script
The `duplicates` command generates a bash script with commented `rm` commands:

```bash
#!/bin/bash
# Cleanup script for duplicate files
# Uncomment the lines you want to execute

# Duplicate group 1 (hash: abc123...)
# KEEP: file1.txt
# rm 'file2.txt'
```

### Directory Sync Script
The `compare` command generates a bash script with commented `mv` commands:

```bash
#!/bin/bash
# Sync script for matching files
# Uncomment the lines you want to execute

# Match group 1 (hash: def456...)
# mv 'old_name.txt' 'new_name.txt'
```

## Examples

### Basic Workflow

```bash
# 1. Generate hashes for a directory
python -m filehasher_v2 generate ~/Documents --algorithm SHA-256 --workers 4

# 2. Find duplicates
python -m filehasher_v2 duplicates Documents.hashes

# 3. Review and execute cleanup script
vim cleanup_duplicates.sh
bash cleanup_duplicates.sh
```

### Incremental Updates

```bash
# Initial hash generation
python -m filehasher_v2 generate ~/Documents --algorithm SHA-256

# Later: update only changed files
python -m filehasher_v2 generate ~/Documents --algorithm SHA-256 --update
```

### Cross-Machine Comparison

```bash
# On machine 1
python -m filehasher_v2 generate /shared/data --output data_machine1.hashes

# On machine 2
python -m filehasher_v2 generate /shared/data --output data_machine2.hashes

# Copy files and compare
python -m filehasher_v2 compare data_machine1.hashes data_machine2.hashes
```

### Performance Testing

```bash
# Test which algorithm is fastest on your machine
python -m filehasher_v2 benchmark

# Test with larger files
python -m filehasher_v2 benchmark --size 100 --algorithms "md5,sha256,blake2b"
```

## Architecture

- **hash_algorithms.py**: Hash algorithm implementations and benchmarking
- **file_scanner.py**: Directory scanning and file discovery with load balancing
- **processor.py**: Advanced multiprocessing with individual thread progress bars
- **hash_file.py**: Hash file format handling with algorithm prefixes
- **cli.py**: Command line interface with signal handling
